# Contributing

Thanks for considering a contribution.

1. Open an issue describing the bug or proposed improvement (do not include secrets or customer data).
2. Keep changes focused and document any new configuration options.
3. Test the extension in Chrome on Windows with a non-sensitive sample Jasper PDF and a test printer.
4. Include clear reproduction steps and relevant sanitized logs in pull requests.

This project currently has no automated integration-test suite; manual Windows testing is required for changes to native printing behavior.
