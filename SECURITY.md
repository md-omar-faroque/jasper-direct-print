# Security Policy

## Reporting a vulnerability

Please do not publish credentials, session cookies, customer reports, or exploitable details in a public issue. Contact the repository maintainer privately with a description, impact, and steps to reproduce. A private security contact can be added in the GitHub repository settings.

## Deployment notes

- Restrict extension host permissions to the JasperReports server domains you operate.
- Review the extension and PowerShell native-host code before deployment.
- Use test reports and non-production accounts while validating changes.
- Never commit credentials, cookies, private report PDFs, or customer data.
